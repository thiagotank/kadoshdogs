# Kadosh Dogs

Tema WordPress customizado do site Kadosh Dogs.

## Estrutura

- `front-page.php`: página inicial
- `template-parts/`: seções reutilizáveis
- `assets/css/main.css`: estilos
- `assets/js/main.js`: JavaScript
- `functions.php`: configuração do WordPress

## Desenvolvimento

Alterações de layout devem ser feitas no código.

Conteúdo e imagens poderão ser administrados pelo WordPress.
